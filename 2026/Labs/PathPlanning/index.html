Model assumptions and sources

These experiments run actual small algorithms on synthetic scenes. They illustrate behavior rather than benchmark a robot. Grid search uses four neighbors. D* Lite retains its g/rhs values between edits. The clearance map conservatively marks entire grid cells that intersect expanded obstacles. The any-angle and sampling experiments use uniform Euclidean distance cost. Theta* uses cell centers and a 0.2-cell circular footprint. PRM uses a finite, fixed-k roadmap. RRT* retains the tree, rewires neighbors and propagates descendant costs; Informed RRT* directly samples the improvement ellipse after a solution exists. Their finite budgets do not certify optimality. Local control compares constant-velocity sampling with a simplified MPPI-style sequence optimizer, using a unicycle model and ideal prediction of the moving obstacle. It omits acceleration limits and uses sampled collision checks. Pose imagination tests geometric candidate motions and does not implement Chirikjian’s affordance learning, PRIMP, or RAIL.
