# CISC 647 — Perception: Classical Computer Vision

The two folders contain the same data and ROS 2 package structure:

- `student/`: starter code with focused TODOs.
- `answers/`: complete reference code used to verify every experiment.

Students work directly with `colcon` and the ROS 2 command line; there are no
build, topic, or run wrappers. Begin with `student/README.md`, then use
`student/ROS2_HANDS_ON.md` for the command sequence attached to each lecture
topic. The prebuilt download archives live in `../../Data/` rather than beside
the editable source.
