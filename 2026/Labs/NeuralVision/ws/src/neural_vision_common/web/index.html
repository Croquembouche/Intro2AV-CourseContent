How to read the view

Each cube is a scalar value. Brightness is scaled within each map or feature group; compare the numbers for exact values. Cyan/blue is positive, purple is negative, and dark is zero.

Solid lines connect individual values. Gold dashed lines group whole tokens; pink marks the selected key token. Moving dots trace relationships, not the timing of computation.

CONTINUE WITH ROS 2

The same networks, as ROS nodes

Your drawing becomes a standard Image message. Each model node publishes its prediction and the internal values shown here.

Download the ROS 2 packages

Use the README in the download for setup. Once the packages are built and sourced:

ros2 launch neural_vision_demos all.launch.py

Follow an image through the system

ros2 node list
ros2 topic info /neural_demo/input --verbose

Record and replay your drawing

ros2 bag record -o my_digits /neural_demo/input
# Stop recording with Ctrl+C, then:
ros2 bag play my_digits
