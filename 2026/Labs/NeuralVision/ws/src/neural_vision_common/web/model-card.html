LECTURE 03 / MODEL PROVENANCE

The models behind the explorer

These three trained MNIST digit classifiers make each architecture inspectable. All displayed weights, activations, attention matrices and predictions come from the included models. The hosted website computes on your device in a browser worker. In the downloaded ROS 2 version, the drawing becomes an Image message and separate model nodes compute the results. Both use the same trained weights and expose the same intermediate tensors.

How they were trained

Fixed seed 647; 55,000 training images, 5,000 validation images, and the official 10,000-image test split. The best validation epoch was selected before a final test evaluation. Training used AdamW, small random translations, six epochs for MLP/CNN and twelve for the transformer. The 30 included examples are the first three test images of each class, without filtering for correct predictions.

The model weights are included. The ROS nodes use NumPy; the hosted website uses an equivalent JavaScript forward pass. PyTorch and a GPU were used to train this release; students need neither to run it. The bundled MODEL_CARD.md contains architecture details and reproduction commands.

Reading the pictures

  • The MLP shows every unit and all incoming connections for the selected neuron. Its hidden layers have 300 and 100 units. Zoom out or pan to see the ends of long layers.
  • CNN convolution maps show responses after activation and use per-map color scales to reveal structure. The numeric inspector shows actual products, bias, activation and pooling values.
  • Transformer attention rows sum to one over 17 tokens, including CLS. The grid shows 16 patch weights and lists CLS separately. The bars show one value dimension; the model mixes all dimensions and all heads.
  • Gold dashed lines group whole tokens. For an attention cell, gold identifies the query and pink the key; the grid and bars show the entire query row used for value mixing. Block-output links summarize one head’s mixing into a whole token. The selected scalar also depends on projections, residuals and the feed-forward network. The classifier applies LayerNorm before its class weights.
  • The Network input preview belongs to the displayed prediction. With Live off, editing the drawing leaves this preview unchanged until Update prediction.
  • Attention weights are mixing coefficients, not guaranteed explanations of a prediction or labels for relationships between objects.
  • The parameter controls modify inference without retraining. Removing positions, disabling a neuron or changing the activation can reduce accuracy.
  • A blank or unfamiliar drawing still receives digit scores: there is no unknown class. These are teaching models for handwritten digits, not general object detectors.

Relation to the lecture

The slides use small illustrative networks and 3×3 neighborhoods to introduce the ideas. This CNN uses learned 5×5 filters; all three demos classify digits 0–9. These are a fully connected baseline, a compact CNN and a compact global-attention ViT. The lecture’s ResNet, feature pyramids and shifted-window attention are separate examples, not stages in these models.

Correctness checks

The 9 September 2026 audit passed 133 browser/reference cases and 337,913 numerical comparisons, with maximum absolute difference 0.000005514. It checked 16,018 unit inspections, including every displayed unit for one reference input per model and selected units under interventions. Calculations were reconstructed from tensors independently of the visual labels. Small rounding differences between JavaScript and the ROS float32 implementation are expected. These checks do not guarantee accurate classification of every drawing.
